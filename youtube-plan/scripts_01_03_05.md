# 台本 #1・#3・#5(アバター出演・各30秒前後)

共通ルール
- アバター名・口調はチャンネルで固定する(例: 宮崎弁まじりの親しみやすいナビ役)。
- 画面は「アバター(下1/3)+ 実演画面(上2/3)」。字幕は大きく、1行12文字以内。
- 概要欄に「AIアバターで制作」「AIの出力は必ず内容を確認して使ってください」を入れる。
- 〔 〕内は画面の指示、「 」はアバターのセリフ。秒数は目安。

---

## #1 メニュー紹介文をAIで作る

タイトル案: 宮崎の飲食店さん、メニュー文まだ手書きですか?

| 秒 | 画面 | セリフ |
|---|---|---|
| 0-3 | 〔手書きメニューを悩む手元の画像+大字幕「メニュー文、30分かけてない?」〕 | 「メニューの説明文、1品に30分かけてませんか?」 |
| 3-8 | 〔ChatGPTの入力欄。「チキン南蛮、宮崎の老舗、タルタル自家製、50文字で」と入力〕 | 「AIにこう入れるだけ。料理名、お店の特徴、文字数。この3つです」 |
| 8-16 | 〔出てきた3パターンを順に表示。「しっとり系」「元気系」「観光客向け」とラベル〕 | 「すると、しっとり系、元気系、観光客向けの3パターンが10秒で出ます」 |
| 16-23 | 〔「もう少しカジュアルに」と追加入力→修正版が出る〕 | 「気に入らなければ『もう少しカジュアルに』と言うだけ。何度でも直せます」 |
| 23-27 | 〔完成したメニュー表の例+字幕「価格・産地は必ず自分で確認」〕 | 「ただし、産地や価格は必ずご自身で確認してくださいね」 |
| 27-30 | 〔「保存して使ってね」+次回予告〕 | 「保存しておくと便利です。次は直売所のPOPを作ります」 |

撮影メモ: 実画面は事前に録画して等倍〜1.2倍速。入力文は画面に残して視聴者がコピーできるようにする。

## #3 直売所のPOPを30秒で作る

タイトル案: 農家さん必見、直売所のPOPが30秒で完成

| 秒 | 画面 | セリフ |
|---|---|---|
| 0-3 | 〔空っぽのPOP用紙+大字幕「POPの文句、毎回悩む」〕 | 「直売所のPOP、毎回何を書くか悩みませんか?」 |
| 3-9 | 〔入力欄に「宮崎産の完熟マンゴー、甘さが自慢、贈答にも、POP用の短い文を3つ」〕 | 「商品名、売りのポイント、用途。この3つをAIに伝えます」 |
| 9-17 | 〔POP文が3つ表示。「キャッチ型」「食べ方提案型」「ギフト型」〕 | 「キャッチ型、食べ方提案型、ギフト型。3種類のPOP文が出ました」 |
| 17-24 | 〔Canva等の無料テンプレに貼り付けて完成。画面上でPOPが仕上がる〕 | 「あとは無料のデザインツールに貼るだけ。印刷すれば完成です」 |
| 24-27 | 〔字幕「"日本一""絶対"などの表現は根拠を確認」〕 | 「『日本一』などの言い切りは、根拠を確認してから使いましょう」 |
| 27-30 | 〔「保存して次の収穫期に」+次回予告〕 | 「保存して、次の収穫期にどうぞ。次は口コミ返信です」 |

撮影メモ: 使うデザインツールは無料プランで足りるものを一つに決めて固定する。マンゴーの画像は自分で撮影したものか、フリー素材の許諾が明確なものを使う。

## #5 口コミ返信をAIに任せる

タイトル案: Googleマップの口コミ返信、AIに任せたら?

| 秒 | 画面 | セリフ |
|---|---|---|
| 0-3 | 〔星1〜5の口コミ画面(架空の例)+大字幕「口コミ返信、後回しにしてない?」〕 | 「口コミ返信、つい後回しにしていませんか?」 |
| 3-10 | 〔架空の良い口コミ「料理が美味しかった」を貼り、「お礼の返信を3行で」と入力〕 | 「口コミ本文をAIに貼って、『お礼の返信を3行で』と頼みます」 |
| 10-17 | 〔丁寧な返信文が表示〕 | 「はい、丁寧な返信が10秒で完成です」 |
| 17-24 | 〔架空の厳しい口コミ「待ち時間が長い」に対し、「謝罪と改善を伝える返信、言い訳なし」と入力→返信文〕 | 「厳しい口コミも大丈夫。『謝罪と改善を伝えて、言い訳はなし』と指示します」 |
| 24-28 | 〔字幕「お客様の個人情報は入力しない」「最後は自分の言葉に整える」〕 | 「お客様のお名前などは入力せず、最後はご自身の言葉に整えてください」 |
| 28-30 | 〔「保存して使ってね」〕 | 「保存して、今日の返信からどうぞ」 |

撮影メモ: 画面に出す口コミは必ず架空の文面にする。実在の口コミは使わない。

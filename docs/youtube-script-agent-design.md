# YouTube台本作成AIエージェント 設計書（ドラフト）

## 1. 目的
YouTube台本を書くAIエージェントを開発する。
依頼者が用意した資料フォルダ（台本作成マニュアル・お手本台本・台本作成のコツ）を読み込み、その内容を前提にして台本を生成する。

## 2. 入力（ナレッジフォルダ）
| 種別 | 内容 | エージェントでの使い方 |
|---|---|---|
| マニュアル | 台本作成の手順・ルール | システムプロンプトの基本方針として常時参照 |
| お手本台本 | 完成度の高い台本の実例 | 構成・文体・テンポの手本（few-shot） |
| コツ集 | 台本作成のノウハウ | 生成後のセルフチェックリスト |

> 現状このリポジトリにはナレッジフォルダがないため、受領後に `knowledge/` へ配置する。

## 3. エージェントの流れ
1. **読み込み**: フォルダ内の全ファイルを読み、要点を要約（マニュアル／手本／コツに分類）
2. **ヒアリング**: テーマ・ターゲット・動画尺・トーンを確認（不足分のみ質問）
3. **構成案**: フック → 本編 → まとめ・CTA の流れで構成案を作成し、ユーザー確認
4. **台本生成**: お手本の文体・テンポに合わせて本文を作成
5. **セルフチェック**: マニュアルとコツ集の項目に照らして自己採点し、不足を修正
6. **出力**: 台本（Markdown）＋ 修正履歴

## 4. 構成
```
knowledge/        # マニュアル・お手本・コツ（ユーザー提供）
agent/
  system_prompt.md   # 役割・ルール・出力形式
  checklist.md       # コツ集から作るチェック項目
output/           # 生成した台本
```
